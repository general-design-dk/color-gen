# design.md — 색칠요정

> 작성일: 2026-10-04 · 최소 토큰만 정의 (확장은 필요할 때)
> 레퍼런스 무드: 흰 배경, 큰 굵은 타이틀, 넓은 여백, 둥근 카드와 알약형 버튼, 흑백 도안이 주인공인 화면

---

## 1. 레이아웃 개요

```
[ 색칠요정 ]  ← 큰 타이틀, 글자 아래 옐로우 형광펜 하이라이트
 짧은 한 줄 설명 (회색)

┌──────────── 카드 ────────────┐
│  [ 도안 캔버스 (세로형) ]        │
│                               │
│  [ 키워드 입력 (크게) ]          │
│  (공주)(공룡)(유니콘)…          │
│  [ ███ 만들기 (옐로우) ███ ]    │
└───────────────────────────────┘
```

- 탭 메뉴, 부가 정보 영역 없음.
- 넓은 화면: 카드 안에서 캔버스(왼쪽), 입력·버튼(오른쪽) 2단. 좁은 화면: 위아래 1단.

## 2. 컬러

| 토큰 | 값 | 용도 |
|---|---|---|
| `color-primary` | `#FFD43B` | 브랜드 옐로우. 만들기 버튼, 타이틀 하이라이트 |
| `color-primary-hover` | `#FCC419` | 만들기 버튼 hover·pressed |
| `color-on-primary` | `#111111` | 옐로우 위 텍스트·아이콘 (블랙) |
| `color-text` | `#111111` | 기본 텍스트, 타이틀 |
| `color-text-sub` | `#6B6B6B` | 설명, placeholder |
| `color-text-disabled` | `#B0B0B0` | 비활성 텍스트 |
| `color-bg` | `#FFFFFF` | 페이지 배경, 도안 캔버스 |
| `color-surface` | `#F5F5F5` | 입력창 배경, 칩 배경, 캔버스 바깥 여백 |
| `color-border` | `#E5E5E5` | 카드·입력창·보조 버튼 테두리 |
| `color-toast-bg` | `#111111` | 토스트 배경 (텍스트는 `color-bg`) |
| `color-error` | `#E03131` | 에러 아이콘·강조 |

- 만들기 버튼 = `color-primary` 배경 + `color-on-primary` 텍스트.
- 비활성 버튼 = `color-surface` 배경 + `color-text-disabled` 텍스트.
- 보조 버튼(다운로드·인쇄·돌아가기) = `color-bg` 배경 + `color-border` 테두리 + `color-text` 텍스트.

## 3. 타이포그래피

폰트: **Pretendard** (한글·영문 공통), 대체 `system-ui, sans-serif`

| 토큰 | 크기 / 행간 / 굵기 | 용도 |
|---|---|---|
| `text-display` | 48 / 56 / 800 (모바일 32 / 40) | 로고 타이틀 "색칠요정" |
| `text-subtitle` | 20 / 30 / 400 (모바일 16 / 24) | 타이틀 아래 한 줄 설명 |
| `text-input` | 28 / 36 / 700 (모바일 22 / 30) | 키워드 입력창 (크고 단순하게) |
| `text-button` | 20 / 28 / 700 | 만들기 버튼 |
| `text-body` | 16 / 24 / 500 | 칩, 보조 버튼, 토스트 |
| `text-caption` | 14 / 20 / 400 | 안내 문구 |

- 단위 px. 자간은 타이틀만 `-0.02em`, 나머지 기본.

## 4. 모서리 (Radius)

| 토큰 | 값 | 용도 |
|---|---|---|
| `radius-card` | 24px | 메인 카드 |
| `radius-input` | 16px | 키워드 입력창, 캔버스 |
| `radius-full` | 9999px | 버튼, 칩 (알약형) |

## 5. 간격 (Spacing)

| 토큰 | 값 |
|---|---|
| `space-xs` | 8px |
| `space-sm` | 12px |
| `space-md` | 16px |
| `space-lg` | 24px |
| `space-xl` | 40px |

- 페이지 좌우 여백: 모바일 `space-md`, 넓은 화면 `space-xl`
- 카드 안쪽 여백: `space-lg`

## 6. 컴포넌트 크기

| 요소 | 높이 | 비고 |
|---|---|---|
| 만들기 버튼 | 64px | 가로 꽉 채움 |
| 보조 버튼 | 48px | |
| 키워드 입력창 | 72px | 테두리 없이 `color-surface` 배경, 포커스 시 `color-text` 2px 테두리 |
| 추천 칩 | 40px | `color-surface` 배경, 선택 시 `color-primary` 배경 |

## 7. 기타

- 그림자: 사용하지 않음 (테두리로 구분). 토스트만 `0 4px 16px rgba(0,0,0,0.12)`.
- 다크 모드: 지원하지 않음.
- 도안 캔버스는 항상 흰 배경 (`color-bg`) — 인쇄 결과와 동일하게 보이도록.
