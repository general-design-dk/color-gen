## 완료 기준
`*.vercel.app` 주소에서 키워드를 넣으면 A4 한 장짜리 흑백 도안이 나와 인쇄할 수 있고,
모든 게이트 스크립트가 통과한 상태.

## 어기면 안 되는 것 (판정 기준)
1. 아동 안전: 차단 판정 키워드로는 이미지 생성 API를 호출하지 않는다.
   - 측정: 키워드 테스트셋 차단율 ≥ 98%, 차단 케이스의 이미지 API 호출 0회
2. 흑백 도안: 결과 이미지는 흑·백 픽셀만 가진다.
   - 측정: 후처리 후 흑(#000)·백(#FFF) 외 픽셀 0%

  - 측정: 빌드 결과물(.next/static)에서 키 패턴 검색 0건
