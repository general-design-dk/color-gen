# R3. 파이프라인

| STEP | 단계 | 입력 | 출력 | 상태 |
|---|---|---|---|---|
| 1 | 화면·기능 기획 | prd.md | userflow.md, 화면 명세 | ✅ 완료 |
| 2 | 스타일 토큰화 | design.md | 토큰 파일 | |
| 3 | UI 구현·컴포넌트화 | 화면 명세, 토큰 | 정적 화면(상태 4개), 컴포넌트 | |
| 4 | 피그마 구현 | STEP 3 화면 | 피그마 파일 (변수·컴포넌트·화면) | |
| 5 | 피그마 정리·동기화 | STEP 4 피그마 | 갱신된 토큰·에셋 | |
| 6 | 기능 구축 | 확정 UI, prd §7~8 | API, 상태 관리 | |
| 7 | UX 보강 | 동작하는 서비스 | 인터랙션 | |
| 8 | 디자인·기능 테스트 | 완성 서비스 | 테스트 리포트 | |

## 되돌아가는 지점
- STEP 5 토큰 변경 → STEP 2 토큰 파일에 반영
- STEP 8 디자인 결함 → STEP 3 / 기능 결함 → STEP 6

## 실패 처리
- 같은 게이트 3회 연속 실패 시 멈추고 사람에게 보고

## 피그마 단계
- STEP 4·5는 필수. Figma MCP가 연결되지 않으면 STEP 6으로 넘어가지 않고 대기
